# Storage and file limits

## Storage by plan

### Free
<!-- tiers: free -->

A Free workspace has 2 GB of storage in total. A single file can be up to 100 MB.

### Pro
<!-- tiers: pro -->

A Pro workspace has 50 GB of storage per seat, pooled across the workspace. A team of 10 seats has 500 GB. A single file can be up to 2 GB.

### Enterprise
<!-- tiers: enterprise -->

An Enterprise workspace has 1 TB of pooled storage. A single file can be up to 5 GB.

More storage is sold as an add-on:

| Add-on | Price |
|---|---|
| 500 GB | $900 per year |
| 1 TB | $1,800 per year |

Order an add-on through your account manager or in **Settings > Billing > Add-ons**.

## When storage is full

New uploads are blocked. Existing files stay available and nothing is deleted. Owners and admins get an email at 80% and at 100% of the limit. To free space, delete files and then empty the trash: files in the trash still count for 30 days.

## An upload fails

1. Check the file size against the limit for your plan.
2. Check **Settings > Workspace > Storage** for free space.
3. Try a different network. Uploads over 1 GB need a stable connection and resume only in the desktop app.
4. Rename the file if its name has characters such as `#`, `%` or `?`.

## File previews

Fernhill previews images, PDF files, plain text, Markdown and common video formats in the browser. Other files are downloaded.
